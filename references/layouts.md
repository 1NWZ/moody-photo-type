# 随机版式库

根据用户提供的五张参考提炼三类版式。前两张属于同一上下分区结构，后三张分别提供微型信息组与纵向大字参考；不得把同类重复样图当成额外抽样权重。以下比例是便于复用的设计范围，不是对参考图的精确测量。只借鉴文字大小层级、位置及留白，不复制原文、品牌、联系方式、日期、时间或参考照片。

## 三种版式

所有坐标和比例相对于最终画布。`box` 为 `[left,top,width,height]`，字号比例为字体像素字号/画布宽；实际字形大小由字体决定。每块的真实字形包围盒必须落在框内，不拉伸字体，不靠自动缩小到范围外塞入文字。

| 版式 ID | 结构与字号范围 | 适用条件 |
| --- | --- | --- |
| `split` | 上方标题：字号 10%–16% W，框 `[.15,.13,.70,.16]`；下方正文：字号 4.5%–7.5% W，框 `[.20,.70,.60,.23]`；可选四角小字：字号 1.8%–3.5% W | 上下都有文字空间，中部需要留给照片；主标题以 1 行短词组为主，下方 2–4 行，具体以实测能放下为准 |
| `micro` | 中部偏窄的 1–3 列微型信息组，字号 1%–1.6% W（1080 宽约 11–17 px）；左/中/右框分别为 `[.25,.46,.12,.08]`、`[.40,.46,.25,.08]`、`[.68,.46,.12,.08]`；各列左对齐、顶对齐 | 照片细节主导，中央有干净背景留白；以 2–5 行极短原创短语试排，不编造联系方式填版 |
| `vertical` | 中轴 5–7 行大字；字号 8.5%–9.5% W，默认 9%；框 `[.175,.20,.65,.60]`；实际文字组占宽 35%–65%、高 30%–60% | 中轴文字与照片可共同阅读，允许主体在前遮住部分文字，类似用户最后两张参考的尺度与节奏 |

`split` 四角可选框：左上 `[.04,.025,.25,.055]`，右上 `[.71,.025,.25,.055]`，左下 `[.04,.93,.25,.045]`，右下 `[.71,.93,.25,.045]`。没有真实且必要的辅助内容就省略，不强制日期、时间、编号或装饰符号。默认白字；参考中的黄色、绿色、窄长字形和白色外框不自动成为本 skill 的全局要求。

`vertical` 行间起点间距/字号为 1.18–1.30（默认 1.24）；其他版式默认 1.05–1.12，可在 1.0–1.30 内微调。微型文字属于有意的小字号风格，不能再套用旧版统一 8.5%–9.5% 或占高 30% 下限。

## 先筛选，再随机

1. 读图并识别主视觉主体和背景留白，按上述条件生成该图可行的候选，给每种候选准备适配的原创文案和分行。相同照片不同候选可以使用不同长度文案，含义和依据一致。不要把一段长文强塞三种模板。
2. 主体永远在文字前。微型信息不能像人脸参考那样直接压在脸上；若脸部等主体占满中央，应排除 `micro`。上下空间不足排除 `split`；中轴严重遮字排除 `vertical`。景物主图也要明确保护主树、主建筑等主体，不把整张照片无差别当成前景。
3. 将可行候选放入 item 的 `layouts`；脚本等概率抽取一类。候选有两类以上时排除上一张刚用过的类，减少连续重复。只剩一类时直接使用，不强迫轮换。单张也随机。没有可行候选时说明构图限制，不退回文字覆盖主体。
4. 新批次未指定 `layout_seed` 时生成一个随机种子，写入 `layout.json`；用户只改文案或局部返修时固定上次 `layout_id`（仅保留该候选），不重新随机整组。相同候选、顺序和种子可复现选择。
5. 固定的是每类版式的尺度范围与块位置，不是全组一个字号、一个中心。整组仍统一调色、字色与字体风格；只在所选版式允许的范围内调整。分区位置按模板设置，不能为遮挡问题随意漂移。

## 执行与审片

使用 `render_batch.py` 的 `layouts` 路径；它支持多块文字、不同字号、左右对齐和随机选类，且要求主体蒙版。它逐块测量并拒绝溢出，不自动缩字。每块的 `font_size`、`box`、`text_bounds_before_occlusion` 以及选中的 `layout_id` 均记录在输出中。

先检查每个候选的文案长度和主体遮挡再交给脚本；几何校验不识别主体，也不判断小字或遮挡后的语义。输出后逐张检查：主体边缘完整，重要词未被全部挡掉，微型文字在原尺寸清晰，分区之间留白充分。失败时修正文案/蒙版或移除不适用候选，在已记录版式上返修；不能声称一定复刻某款未提供的字体。
